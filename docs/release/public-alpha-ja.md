# パブリックアルファノート

[English](public-alpha.md)

Suisuiの最初のパブリックアルファは、日本語を主言語として、一人で複数の仕事や個人プロジェクトを整理したい方に向けた評価版です。ローカルファーストとレビュー後実行を守りながら、簡単な入力から高度な計画・実行管理まで段階的に使えることを目指します。

## 対象ユーザー

- 個人開発者、クリエイター、フリーランス、小規模事業者
- タスク管理だけでなく、計画、期限、成果物、振り返りまで一か所で扱いたい方
- 音声や自然な文章で仕事を渡し、AIの提案を自分で確認して進めたい方
- クラウドへ全面的に預けず、ローカルのデータと明確な承認境界を重視する方

## アルファ版で確認したい価値

- 初めて触る人が、説明書を熟読しなくてもInboxまたはVoice Commandから仕事を登録できる
- 簡単なタスクは短い操作で完了でき、必要なときはプロジェクト、期限、予定、文書まで詳しく扱える
- AIが提案した内容と実行対象が明確で、利用者が安心して承認または修正できる
- Todayを見るだけで、今日やることと見落としが分かる

## 主要ワークフロー

### 1. 音声・文章から計画を作る

大まかな目標を話すか入力すると、Suisuiが不足情報を確認してAction Planを作ります。プロジェクト、タスク、期限を確認し、承認後に実行します。

### 2. 今日の優先順位を決める

Todayで期限、優先度、未完了のフォローアップを確認し、次に着手するタスクを選びます。

### 3. 予定とリマインダーを準備する

Apple CalendarやRemindersへ追加する内容を先に表示します。利用者が対象、日時、内容を確認し、承認したものだけを反映します。

### 4. 成果物の下書きを作る

プロジェクトに紐づくMarkdown文書を提案し、保存先と内容を確認してから作成します。既存ファイルを無断で上書きしません。

### 5. 完了と次の行動を振り返る

Doneで完了した仕事を確認し、残ったフォローアップや次の候補を整理します。

## 安全性と承認境界

- Suisuiはローカルファーストで、プロジェクト、タスク、Knowledge、監査情報をローカルへ保存します。
- APIキーやプロバイダートークンはmacOS Keychainへ保存します。
- 書き込み、予定・リマインダー作成、成果物作成は、内容を表示して承認後に実行します。
- 秘密情報をログ、設定DB、テスト証跡、スクリーンショットへ平文で残さないことを品質契約にしています。
- 権限がない外部操作や、対象が曖昧な破壊的操作は実行しません。

## 対象範囲

- macOSメニューバーアプリとProject Board
- 音声・文章からAction Planを作る経路
- Inbox、Today、Projects、Schedule、Done
- ローカルのProject、Task、Knowledgeストレージ
- Apple Calendar、Reminders、Notificationsアダプター
- Markdown成果物の作成
- 期限監視と通知の基盤
- 署名、Notarization、DMG、Sparkle更新のパッケージング基盤

## まだ対象外の機能

- チーム、組織、ロール、共有ワークスペース
- クラウド同期と複数端末間の同期
- GitHub、Gmail、Slack、Google Drive、Notionなど外部SaaSへの接続
- 外部MCPランタイム
- 大規模な全文RAGインデックス
- メール送信、Slack投稿、破壊的なローカルファイル操作の自動実行

## 既知の制限

- STT/TTSのローカルモデルは同梱されず、利用者がファイルまたはディレクトリを設定します。
- AI機能には、対応プロバイダーのAPIキーとネットワーク接続が必要です。
- macOS連携は、利用者が許可した権限の範囲に限られます。
- 署名、Notarization、Sparkle配布の最終確認は、必要な証明書と秘密情報を持つリリース用Macで行います。
- 自動検査に合格しても、最終リリース候補では日本語・英語、狭いウインドウ幅、キーボード操作、手動VoiceOverを別途確認します。
