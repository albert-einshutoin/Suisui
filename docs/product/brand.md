# Suisui Brand Foundation

## Identity

- Product name: `Suisui`
- Japanese notation: `Suisui`
- English notation: `Suisui`
- Category: AIパーソナルプロジェクトマネージャー
- Japanese tagline: 声から、仕事がすいすい進む。
- English tagline: Speak it. Review it. Move it.
- Primary copy: Suisuiに話すだけ。あとは確認して、仕事を前へ。

## Product promise

Suisui should feel easy before it feels powerful. Voice and text make input
simple, review-before-write keeps every change understandable, and deeper
automation remains available without making the first interaction look like a
complex AI tool.

The name should communicate:

- input is easy;
- organization is smooth;
- work does not stall;
- a fish moves quietly forward;
- the product is approachable rather than intimidating.

## Visual mark

The primary mark is the current abstract blue symbol: it can be read as both a
voice waveform and a fish moving forward. The small warm-colored dot is the
human review/decision point between speech and action.

Use `Suisui` as the proper product name. Use `すいすい` inside Japanese copy
when the adverbial, friendly reading is more natural. Do not use `SUI SUI` as
the primary wordmark.

## Compatibility boundary

The public app bundle, executable, window titles, onboarding, backups, and
release artifacts use `Suisui`. SwiftPM module names, the bundle identifier
`dev.suisui.app`, the existing Application Support directory, database name,
environment variables, and stable plist integration keys retain `Suisui` for
this migration. This preserves upgrades and existing local data; those
internal identifiers are not public brand copy.
